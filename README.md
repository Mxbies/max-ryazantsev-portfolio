# Max Ryazantsev — Portfolio

Версия 2: русскоязычное портфолио на HTML, CSS и JavaScript. Серверная часть и сборка не нужны.

## Новое в версии 2

- Живой фон со световыми лентами, мягкими оттенками и реакцией на курсор.
- Ограничение частоты отрисовки фона: до 30 кадров/с на компьютере и до 22 на телефоне. При скрытой вкладке отрисовка останавливается; системная настройка уменьшения движения отключает анимацию.
- Более выразительное оформление портрета, кнопок, орбитальной композиции и галерей.
- Скруглённые изображения, карточки и увеличенный просмотр.
- Из материалов «Диастоп» убраны видимые панели PDF и телефона. Две версии логотипа показаны отдельными слайдами.
- У логотипа и пятого изображения фестиваля убраны плашки ВК, у видеокадра — интерфейс социальной сети.

Обрезка выполняется точно по координатам при отображении: в галереях через CSS, в увеличенном просмотре через SVG. Исходные изображения в `assets/` сохранены без изменений. Ссылка «Исходник» открывает полный исходный файл.

## Как посмотреть

1. Распакуй архив.
2. Открой папку `max-ryazantsev-portfolio`.
3. Дважды нажми на `index.html` — сайт откроется в браузере.
4. Для редактирования в VS Code выбери «File → Open Folder» и эту папку.

Можно также открыть страницу через расширение Live Server в VS Code.

## Где что менять

- `index.html` — тексты, контакты, порядок разделов и изображения.
- `style.css` — цвета, размеры, расстояния и мобильная версия. Основные цвета находятся в `:root` в начале файла.
- `script.js` — меню, выбор навыков, переключение галерей и увеличенный просмотр.
- `assets/` — исходные изображения из твоего репозитория; их содержимое не изменено.

В архиве нет повторяющихся копий изображений из корня старого репозитория и вложенной папки `assets/assets/`: страница использует только `assets/имя-файла`. Удалять старые копии на GitHub для работы обновления не требуется.

В репозитории отсутствуют `diastop-1.jpeg` и `diastop-2.jpeg`. Для двух слайдов «Диастоп» используется имеющийся `diastop-logo.png`: отдельно показаны цветная и белая версии из исходного документа. Стрелки и счётчик работают для обоих слайдов. Личная фотография находится в разделе «Обо мне».

## Как обновить сайт на GitHub Pages

Сайт публикуется через GitHub Pages из ветки `main`, папка `/(root)`. Для отправки изменений нужен авторизованный доступ к репозиторию.

Папка `assets/` в репозитории уже содержит используемые изображения. Для обновления до версии 2 достаточно заменить три файла в корне репозитория. Изображения перезагружать не нужно.

1. Открой https://github.com/Mxbies/max-ryazantsev-portfolio и войди в свой аккаунт.
2. Переключись на ветку `main`.
3. В корне репозитория нажми **Add file → Upload files**.
4. Перетащи из новой папки именно `index.html`, `style.css` и `script.js`.
5. Напиши название изменения, например `Обновить дизайн и мобильную версию`.
6. Выбери сохранение в `main` и нажми **Commit changes**.
7. В **Settings → Pages** должны быть: **Deploy from a branch**, **main**, **/(root)**.
8. Дождись успешной публикации в разделе **Actions**, затем открой https://mxbies.github.io/max-ryazantsev-portfolio/.

Не загружай в корень ZIP или внешнюю папку `max-ryazantsev-portfolio`: файл `index.html` должен находиться непосредственно в корне репозитория.

## Как проверить после загрузки

- Обнови страницу без кеша: на Mac — Cmd + Shift + R.
- Открой меню на телефоне и проверь все пять ссылок.
- Выбери несколько навыков: описание должно меняться.
- В галерее фестиваля нажми стрелку: счётчик меняется, после шестого кадра возвращается первый. В «Диастоп» переключаются две версии логотипа.
- Нажми изображение, переключи его стрелками и закрой просмотр.
- Открой «Концепция и сценарий» в кейсе «Диастоп».
- Проверь Telegram и кнопку email. Email открывается в настроенной почтовой программе.
- Проверь сайт на телефоне в вертикальном и горизонтальном положении.

## Выполненная локальная проверка

Проверены ширины 320, 375, 540, 768, 800, 801, 1024 и 1440 пикселей: горизонтального переполнения не обнаружено. Проверены мобильное меню, выбор навыков, циклическое переключение галереи, увеличенный просмотр, клавиши стрелок и Escape, возврат фокуса и прямой переход к сценарию. Проверены относительные пути, уникальность идентификаторов и синтаксис JavaScript.

Проверка опубликованного обновления возможна после загрузки файлов на GitHub.
